# Stop. Did you actually attempt the exercises first?

These are reference solutions for Day 1's exercises. They exist so you can
self-check *after* you've written your own version and gotten stuck or want
to compare approaches — not so you can skip straight here.

If you paste your attempt into the chat, you'll get real critique (wrong
assertions, missed edge cases, mocking the wrong layer, etc.) — that's more
valuable than reading a solution, because an interviewer isn't going to
hand you one either.
